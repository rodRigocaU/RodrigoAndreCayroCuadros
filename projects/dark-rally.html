Overview

Dark Rally is a multiplayer off-road racer with bikes, quads, cars, side-by-sides and trucks. Its simulation runs on Photon Quantum, a deterministic, fixed-point ECS where every client must compute exactly the same frame. My job is to analyze, propose and ship improvements to vehicle physics and gameplay without breaking that determinism.

Determinism & Desync Fixes

  • Found shared state that broke simulation determinism: gameplay fields living in prefabs and static variables
  • Moved that state into Quantum Frame components so it is rolled back and predicted correctly
  • Converted floating-point math to fixed-point (FP), removing a source of client desynchronization

Vehicle Physics

  • Surface-dependent friction (asphalt, dirt, sand, water) via PhysicsMaterial in the Quantum DSL
  • Speed-dependent grip, nitro ramp-up and asymmetric suspension damping
  • Two-wheel vehicle physics with a custom rollover-recovery system
  • Two-wheel behaviour isolated behind a flag so four-wheel vehicles stay untouched

What I Learned

Working in a deterministic rollback framework changes how you write gameplay code: every value that affects the simulation has to live in the frame, use fixed-point math and be reproducible bit for bit. Tuning feel (grip, suspension, nitro) inside those constraints, on a live multiplatform game, has been the core of this role.
